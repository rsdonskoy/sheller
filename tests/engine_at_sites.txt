# .at() ratchet table for tests/engine_at_ratchet_gate.cmake: one line per engine
# source file that does bounds-checked subscripting, as "<path> <count>", path
# relative to the project root. The count is a ceiling - the gate fails a file only
# when the real count exceeds it, and reports the ones that have drifted below so
# this table can be tightened. The count unit is occurrences, not lines: a line
# carrying two ".at(" is two subscripts, and counting the line would make the second
# one free (that is what this table used to count, and it was measured green while a
# registered file went from 1 to 2).
#
# Baseline taken with the per-site classification (38 sites; the classification
# lists them one per line, so its 38 entries and this table's 38 occurrences are
# the same count today - no line in these five files holds two).
# No file may go up without a classification decision first: a guest-controlled index
# is supposed to get an explicit check plus the file's own failure channel, not a new
# .at() and not a bigger number here.
